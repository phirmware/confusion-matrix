How the scoring works

Names are lowercased, accents normalized, punctuation converted to spaces, and split into sorted tokens. Sorting makes the outcome independent of the original word order.

Every account/document token pair receives a Jaro-Winkler score. The closest available pairs are selected first, using each token only once. This is a deterministic greedy alignment—not a globally optimal assignment—and prevents reusing one document word for several account words.

Base score = average similarity of the aligned pairs × 100. The number of pairs equals the shorter name's token count, so a missing middle name is handled by the explicit penalty rather than counted as both a zero-similarity word and a penalty.

Final score = clamp(base score − |account token count − document token count| × penalty, 0, 100). Penalties apply symmetrically to extra and missing words.

At the default settings, “Alexander James Vance” and “Vance Alexander” score 100 − 15 = 85%, so they pass an 80% threshold. Predictions use unrounded scores; displayed scores are rounded. Inputs without letters or numbers are invalid, not classified.
